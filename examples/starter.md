## [basic] Производная
Чему равна производная $x^n$ при положительном целом $n$?
:::answer
$$\frac{d}{dx}x^n=nx^{n-1}$$
:::notes
Для $n=3$ получаем $3x^2$.
:::tags
математика, производные

## [basic] Преобразование массива
Как получить квадраты чисел без изменения исходного массива?
```javascript
const numbers = [1, 2, 3];
```
:::answer
```javascript
const squares = numbers.map(n => n * n);
```
Результат: `[1, 4, 9]`.
:::tags
код, javascript

## [basic] Объяснить решение
Почему для длинного ответа полезно заранее определить критерии самопроверки?
:::answer
Критерии помогают проверить, воспроизведены ли главные мысли, а не только знакомые слова. После раскрытия нужно сравнить своё объяснение с обязательными пунктами и честно оценить трудность.
:::notes
Критерии: полнота ключевых мыслей, правильный смысл, самостоятельное воспроизведение.
:::tags
обучение
