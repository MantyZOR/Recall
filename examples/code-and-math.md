## [basic] Производная степени
Чему равна производная $x^n$ при положительном целом $n$?
:::answer
$$\frac{d}{dx}x^n = nx^{n-1}$$
:::notes
Для $n=3$ получаем $3x^2$.
:::tags
математика, производные

## [basic] Квадраты чисел в JavaScript
Как получить квадраты чисел, сохранив исходный массив?
```javascript
const numbers = [1, 2, 3];
```
:::answer
```javascript
const squares = numbers.map(number => number * number);
```
:::notes
Результат — [1, 4, 9]. Метод map создаёт новый массив.
:::tags
код, javascript

## [basic] Изменяемая коллекция в Python
Почему список используют, если элементы коллекции нужно менять?
:::answer
Список — изменяемая коллекция:
- можно заменить элемент по индексу;
- можно добавить или удалить элементы;
- для добавления одного элемента используют append.
```python
items = ["a", "b"]
items.append("c")
items[0] = "x"
```
:::notes
Для самопроверки достаточно назвать изменяемость и один пример изменения. Код: ["x", "b", "c"].
:::tags
код, python
