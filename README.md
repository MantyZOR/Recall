# Recall

Личное приложение карточек для Windows, iPhone и Android: локальные данные, FSRS-7, прямой обмен по домашней сети.

**[Скачать готовое приложение для Windows](https://github.com/MantyZOR/Recall/releases/latest)** · [Подключить телефон](docs/connection-guide.md) · [Что находится в репозитории](docs/github-and-portability.md).

В Releases выбирай **Recall-portable-win-x64.zip**, распакуй весь архив и открой **Recall.exe**. Личные карточки и история в эту сборку не входят.

## Запуск

Открой **Recall.exe**. Небольшое меню запускает службу в фоне, показывает адрес приложения на ПК, адрес телефона с портом и QR страницы подключения. Кнопки: **Открыть на ПК**, **Подключить телефон**, **Остановить**. Закрытие меню оставляет службу работать; остановка освобождает порты.

**Запускать службу при входе в Windows** — отдельный переключатель в меню. По умолчанию выключен. Перед перемещением папки отключи её автозапуск и останови службу, после перемещения настрой его снова.

Для готовой переносимой сборки Windows 10/11 x64 не нужны отдельно Node.js и Rust: Node включён. Распакуй всю папку перед запуском. Каждая новая копия создаёт свои данные и сертификаты; карточки и историю можно перенести полным архивом из настроек.

Для исходников нужны Node.js 24 или новее, `npm ci`, `npm run build` и на Windows `npm run build:launcher`. Старый Start-Recall.cmd также открывает новое меню. Stop-Recall.cmd остаётся запасным способом остановки.

## Телефон: первое подключение и восстановление

Сканируй QR в меню запуска или на ПК открой **Устройства**. Инструкция содержит выбор iPhone/Android, установку локального сертификата, добавление иконки и связывание устройств. Адрес берётся из настройки этой копии.

- [Пошаговое подключение и переустановка](docs/connection-guide.md)
- [GitHub, размеры и переносимая сборка](docs/github-and-portability.md)

ПК и телефон должны быть в одной сети. На iPhone нужен Safari, профиль Recall Local CA и отдельное включение полного доверия. На Android предназначен Chrome и установка сертификата CA; точные названия настроек зависят от производителя. Полный цикл на реальном Android ещё требует проверки.

После установки открывай Recall с новой иконки, свяжи его с ПК через QR/одноразовый код в «Устройствах» и дождись завершения обмена и офлайн-подготовки. Компьютер и один телефон обмениваются напрямую; после этого телефон умеет учиться без ПК, даже с включённым Wi-Fi и недоступной службой.

Если удалил приложение, добавь иконку заново, на ПК отключи старое сопряжение и создай новый код. После обмена вернутся данные, уже переданные ПК; для ещё не синхронизированных изменений нужна сохранённая копия.

Не меняй рабочий IP без необходимости: адрес определяет локальное хранилище телефона. В меню есть настройка HTTPS и разрешение брандмауэра. В Public нужно указать конкретный IP телефона; в Private разрешается локальная подсеть. Windows запросит права администратора. Адреса лучше закрепить в роутере.


## Обучение и материалы

В **Библиотеке** создай колоду и карточку либо выбери **Импорт .md**. Можно вставить текст, выбрать или перетащить файл в открытое окно импорта; перед записью видны ошибки и количество карточек. В этом же окне находится «Набор для ИИ и импорта»: правила формата, запрос для ИИ, шаблон и примеры в одном ZIP. В справке есть короткое пояснение Markdown и переход к импорту.

- [Мини-вики: как работает Recall](docs/mini-wiki.md)
- [Методичка по импорту](docs/markdown-format.md)
- [Набор: методичка, шаблон, пример и запрос для ИИ](docs/recall-import-kit.zip)
- [Шаблон для заполнения](examples/template.md)
- [Пример со словами, формулами и кодом](examples/starter.md)
- [Запрос для подготовки карточек через AI](docs/ai-prompt.md)
- `examples/illustrated.cards.zip` — готовый пример с изображением.

Примеры добавляются только по твоему выбору. Повторный импорт одинакового содержания в ту же колоду пропускает дубликаты; существующие правки он не заменяет.

В **Колоды** нажми значок корзины рядом с настройками колоды и подтверди **Удалить колоду**. Она и её карточки исчезнут из активной библиотеки и обучения. В **Корзине колод** можно восстановить колоду вместе с карточками, историей ответов и расписанием повторений. Карточки, удалённые отдельно раньше, останутся в своей корзине. Удаление и восстановление передаются на второе устройство при синхронизации.

В **Карточки → Статус карточек → Корзина** можно восстановить карточку, удалить её навсегда, удалить выбранные карточки или **Очистить всю корзину**. Перед окончательным удалением показывается подтверждение. Статистика ответов сохраняется, удалённая карточка не возвращается при синхронизации или импорте старого архива в текущую базу. Исторический журнал и старые резервные копии сохраняются.

Раздел **Справка → Как устроен Recall** содержит пять учебных экранов: очередь на сегодня, карточка и оценки, колода и цель, влияние настроек и работа устройств. Кнопки и настройки в примерах можно пробовать без записи в историю. В разделе **Алгоритмы повторения** есть интерактивный график на том же расчёте FSRS-7/FSRS-6 и подробные раскрываемые главы про модели, оценки, интервалы и персонализацию; SM-2 и Лейтнер описаны отдельно. На телефоне открой меню вверху справа и выбери **Справка**. Все примеры и поиск работают без сети. Справка скачивается в Markdown с текстовым описанием примеров; исходный текст в `src/ui/wiki-content.ts`, учебные экраны в `src/ui/HelpGuide.tsx` и `src/ui/AlgorithmLab.tsx`. Сборка обновляет `docs/mini-wiki.md` из того же содержания.

В форме цели дата выбирается в календаре внутри формы, который помещается на узком экране.

Поддерживаются вопрос/ответ, ввод, пропуски и изображения. Формулы используют LaTeX, код — блоки Markdown. Картинку можно добавить к вопросу или ответу.

Сначала попробуй вспомнить, затем раскрой ответ и выбери трудность. **Не вспомнил** означает неудачную попытку; **Трудно** — правильный ответ с усилием. Короткий ввод проверяется автоматически, но оценку выбираешь ты. Длинные ответы, формулы и код проверяются вручную. Подсказка отмечается как несамостоятельный ответ.

**Отменить оценку** исключает ошибку из расписания и статистики, сохраняя факт отмены в журнале. Клавиши: Enter/пробел — открыть ответ; 1–4 — оценка; Ctrl+Z — отмена.

Лимит новых карточек учитывается и в профиле, и в колоде. Связанные пропуски разнесены по занятиям. Бюджет времени ограничивает сессию, после паузы можно продолжить.

## Цели и статистика

Выбери дату, колоды, важность тем, минуты в день и желаемое запоминание. До даты цель применяет свой уровень к выбранным колодам; при нескольких целях используется наибольший активный уровень. Затем возвращается уровень колоды.

Прогноз показывает охват, нагрузку и нехватку времени/лимита новых карточек. Расчёт будущей нагрузки использует сценарий ответов «Нормально». Вероятность воспроизведения карточки не является вероятностью сдать экзамен.

Дополнительная практика и проверка перед датой отмечаются отдельно. Проверка проходит без подсказок. Статистика строится по фактическим ответам, отмены учитываются.

Персонализация FSRS-7 доступна на ПК после 400 подходящих наблюдений. Это ограниченный подбор координат с регуляризацией, а не полный оптимизатор upstream. Последние 20% истории служат проверкой; параметры можно применить только при улучшении на этой части. Подсказки и дополнительные упражнения исключены из сравнения прогнозов.

## Обмен

Держи приложение открытым на телефоне, когда ПК доступен в общей сети. Автообмен передаёт недостающие события и изображения после изменений и проверяет изменения с ПК примерно раз в минуту. По умолчанию после **3 неудачных попыток подряд** он ставится на паузу, которая сохраняется после перезапуска. Нажми **Синхронизировать сейчас** в боковой панели или **Синхронизировать** в «Устройствах», когда ПК станет доступен: успешный обмен возобновляет автоматический режим. В **Настройки → На этом устройстве** можно выбрать 1–10 попыток или режим **Только по кнопке**, а также размер текста. В разделе **Оформление** доступны шесть акцентных цветов. Размер текста, акцентный цвет и режим автообмена сохраняются отдельно на каждом устройстве. При отсутствии сети и в свёрнутом приложении новые автоматические попытки не запускаются. Без связи ответы сохраняются локально.

Одновременные ответы сохраняются оба. Конфликтующие правки показываются для выбора версии; до решения карточка не попадает в очередь. Удаление, восстановление и отмена передаются как действия. Повторная передача не создаёт дубликаты.

Индикатор различает локальное сохранение, копию на ПК и подтверждённое получение телефоном. Фоновый обмен при закрытой PWA не предполагается.

## Копии и восстановление

В настройках выбери **Скачать полный архив**. ZIP включает `manifest.json`, `events.json` и вложения. Описание содержит версии ядра, стандартные параметры и источник FSRS; персональные параметры находятся в журнале. Авторизация и сертификаты не экспортируются.

**Восстановить или объединить архив** проверяет структуру и SHA-256 изображений, затем объединяет историю, сохраняя существующие данные. Повторный импорт безопасен. Экспорт Markdown переносит только содержание; для истории нужен полный архив.

После изменений служба создаёт не чаще раза в час до 30 копий SQLite в `data/backups`. Кнопка **Создать копию на ПК** создаёт копию сразу. Сначала заверши синхронизацию: в копию попадают события, уже полученные службой.

SQLite-копии используют общую папку `data/assets`: сохраняй обе папки. Активный `recall.sqlite` нельзя считать полной копией без его журнала WAL.

Если данные интерфейса потерялись, **Export-Backup.cmd** превращает последнюю SQLite-копию в переносимый архив в `data/exports`. Импортируй ZIP в Recall. Скрипт проверяет изображения, записывает новый файл и не заменяет исходную базу. Можно выбрать копию вручную:

```powershell
node scripts/export-backup.mjs --snapshot "D:\AI\Flashcards\data\backups\ИМЯ.sqlite" --assets "D:\AI\Flashcards\data\assets" --output "D:\AI\Flashcards\data\exports\recovered.recall.zip"
```

Ограничения одного импорта: 64 МБ ZIP, 128 МБ после распаковки, 32 МБ на файл, 8 МБ на изображение, 100 000 событий. Экспорт проверяет размер перед выдачей ZIP. SQLite-копия с вложениями сохраняет исходные данные независимо от ограничений переносимого импорта.

Удаление PWA или очистка браузера могут удалить локальную базу. Запрос постоянного хранения в настройках показывает фактический ответ браузера; копии нужны и при положительном ответе.

## Адрес и сертификат

Протокол, IP и порт определяют хранилище телефона. Сохраняй постоянный адрес. При вынужденной смене сначала скачай архив из приложения по старому адресу, затем подключи новое и восстанови данные.

Сертификат сервера рассчитан на год, корневой — на 10 лет. Обновление сохраняет корневой ключ:

```powershell
.\Stop-Recall.cmd
npm run setup:tls -- --address 192.168.1.57 --renew
.\Start-Recall.cmd
```

Закрытые ключи в `certs` доступны владельцу и SYSTEM. Телефону выдаётся профиль `Recall-Local-CA.mobileconfig` с открытым корневым сертификатом. Он содержит только сертификат, без управления устройством. Ключи не входят в экспорт.

При ошибке запуска окно остаётся открытым; журнал — `data/service.log`.

## Исходники и проверки

FSRS-7 выполняется включённым WASM из скалярной реализации Rust fsrs-rs. Источник: коммит `4bc0a0979f95dd01cc653031b6f2a01429e4c32b`, лицензия BSD-3-Clause; файлы — `vendor/fsrs-rs`. Проверенная реализация TypeScript служит резервным вариантом и используется для прогнозов/оптимизации.

FSRS-6 доступен для сравнения и переключения. SM-2 и Leitner сравнивают интервалы; вероятность воспроизведения им не приписывается. Минимумы обучения 1/6/10/30 минут — отдельное правило Recall.

```powershell
npm ci
npm run build
npm test
npm run test:e2e
```

Тесты используют отдельные базы, проверяют историю, отмены, конфликты, TLS, восстановление, офлайн-перезапуск, формулы/изображения и мобильный интерфейс. Эмуляция Chromium не заменяет проверку установленной PWA на реальном iPhone.

Для разработки: `npm run dev` и отдельно `node server/index.mjs --dev`. Rust нужен только для пересборки WASM через `scripts/build-core.ps1`. Интерфейс, математические шрифты, QR-сканер и модель включены в локальный кэш.

В корзине колод доступно окончательное удаление колоды со всеми карточками после подтверждения. Статистика ответов сохраняется; старые архивы и резервные копии остаются. Подсветка блоков кода и методичка по импорту доступны без сети.


## Пакеты для GitHub и пользователей

В репозитории хранятся **код и инструкции**. В разделе **Releases** размещается готовый **Recall-portable-win-x64.zip**: распакуй его и запусти Recall.exe. Ссылки GitHub «Source code» предназначены для разработки. [Что скачать и как устроены пакеты](docs/github-and-portability.md).

`npm run package:source` создаёт дополнительный снимок исходников в out/Recall-source и ZIP. Загружать этот ZIP внутрь репозитория не требуется. Личные базы, карточки, сертификаты, ключи, зависимости разработки и Rust исключаются.

После `npm run build` и `npm run build:launcher` команда `npm run package:portable` создаёт чистую сборку Windows x64 с Node, необходимыми зависимостями и меню. Это приложение для нового пользователя, а не копия текущей базы. Версии, сторонние лицензии и контрольные суммы находятся внутри пакета.

Для пересборки алгоритма нужен Rust; для обычной сборки интерфейса и работы приложения используется уже включённый public/fsrs7.wasm. Сборочные команды создают файлы локально; отправка исходников в GitHub и выпуск версии выполняются отдельно. Лицензии сторонних библиотек сохранены, лицензию собственного кода выбирает владелец.
