# ПК, ноутбук и телефон

Recall обменивается карточками внутри одной сети, без облака. Сегодня телефон может быть в сети с ПК, завтра — в другой сети с ноутбуком. Когда телефон снова встретится с ПК, он передаст изменения, которые получил от ноутбука.

## Один раз подключить каждый компьютер

1. Установи [RecallSetup.exe](windows-install.md) на ПК и ноутбуке. На каждом запусти Recall и включи доступ в частной сети через меню **Настройка сети**.
2. Для компьютера, с которым iPhone ещё не соединялся, открой его страницу настройки в Safari, установи профиль и включи доверие. [Пошаговая настройка телефона](connection-guide.md).
3. В окне Recall на компьютере нажми **Открыть на ПК → Устройства → Создать код подключения**. Открой на телефоне **прежнюю иконку Recall → Устройства → Добавить компьютер** и введи код с ПК. Он действует 10 минут. Повтори для второго компьютера.

Когда подключение сохранено, вводить IP, новый код или сканировать QR больше не нужно. При смене IP Recall ищет компьютер по постоянному имени. Если прежнее подключение было записано по IP, достаточно один раз обменяться с обновлённым компьютером, пока старый адрес доступен. Если он уже изменился, добавь этот компьютер по короткому коду: Recall обновит его подключение, сохранив карточки.

## Как идёт обмен

- На нужном компьютере должна работать служба Recall. Телефон должен быть в той же сети и с открытым приложением.
- Доступные компьютеры обмениваются изменениями автоматически. **Синхронизировать сейчас** сразу проверит все сохранённые подключения. Можно выбрать ручной режим в настройках.
- Пока один компьютер недоступен, другой продолжает обмениваться. Карточки, изображения, оценки, цели и удаления передаются как изменения и не дублируются. В «Устройствах» видно, кто обновился и когда.

## Если компьютер не находится

Сеть Windows должна быть **частной**, а устройства должны видеть друг друга. Гостевая сеть может блокировать связь и локальные имена. Если браузер попросит разрешение на локальную сеть, разреши доступ для Recall. Для проверки адреса открой **Устройства → Настроить → Резервный адрес**. Приложение сверит, что это тот же компьютер, прежде чем сохранить адрес.

Иконка на телефоне хранит карточки по адресу, с которого её установили. Не удаляй её и не переходи на новый адрес ради смены Wi-Fi. GitHub Pages раздаёт веб-приложение и не хранит карточки.
