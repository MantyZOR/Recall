# Методичка по импорту в Recall

Эта методичка объясняет, как готовить учебные файлы самому или с помощью ИИ. Для импорта нужен файл с карточками, а саму методичку и запрос для ИИ загружать в Recall не нужно.

## Быстрый старт

1. Скачай «Набор для импорта» из окна импорта или справки и распакуй ZIP.
2. Открой `template.md` в редакторе текста, замени заготовки своим материалом и сохрани в UTF-8 с расширением `.md`.
3. В Recall нажми «Импорт .md» → «Выбрать .md / .zip» и выбери свой файл. Можно вместо файла вставить его текст.
4. Проверь число карточек, вопросы и сообщения об ошибках. Выбери новую или существующую колоду и нажми «Добавить карточки».
5. Открой несколько карточек в редакторе и включи «Предпросмотр»: проверь код, формулы и полноту ответов.

В наборе есть `examples/code-and-math.md` — готовый учебный пример. Его можно импортировать отдельно. Число карточек после импорта может быть больше числа заголовков: разные номера пропусков создают отдельные карточки.

## Из чего состоит файл

Один Markdown-файл описывает одну колоду. В самом начале можно указать название и настройки:

```yaml
---
deck: "Моя тема"
description: "Что я хочу помнить"
retention: 0.9
---
```

Блок необязателен. `deck` — название, `description` — описание, `retention` — желаемая вероятность вспомнить ответ, от 0.7 до 0.97. Используй точку в числе. Если в названии есть двоеточие или специальные символы, заключи его в кавычки.

При выборе существующей колоды её название и настройки сохраняются. Обычный Markdown переносит содержание карточек. Историю ответов и настройки приложения переносит полный архив Recall из раздела «Настройки».

Каждая карточка начинается **с новой строки без отступа**:

```markdown
## [basic] Короткое название
Текст вопроса.
:::answer
Текст правильного ответа.
```

Нужны два знака `#`, затем пробел, тип в квадратных скобках, ещё пробел и название. Заголовок — подпись карточки; сам вопрос пиши под ним. Между карточками удобно оставлять пустую строку.

Для подзаголовков внутри вопроса или ответа используй `###`, а не `##`: строка с `## ` вне блока кода начинает следующую карточку.

## Три типа карточек

| Тип | Когда использовать | Что обязательно |
| --- | --- | --- |
| `basic` | Определение, формула, код, объяснение | Вопрос и `:::answer` с ответом |
| `input` | Слово, термин или другой ответ, который хочешь набрать | Вопрос и `:::answer` с эталоном |
| `cloze` | Пропуск в предложении или формуле | Текст с `{{c1::ответ}}` |

Типа `image` нет: изображение можно добавить к любой карточке.

### Вопрос и ответ

```markdown
## [basic] Производная степени
Чему равна производная $x^n$ при положительном целом $n$?
:::answer
$$\frac{d}{dx}x^n = nx^{n-1}$$
:::notes
Для $n=3$ получается $3x^2$.
:::tags
математика, производные
```

Всё до `:::answer` — вопрос. Ответ раскрывается во время повторения. Пояснение из `:::notes` показывается после раскрытия.

### Ввод короткого ответа

```markdown
## [input] Resilient
Переведи resilient в значении способности восстановиться после трудностей.
:::answer
стойкий
:::aliases
устойчивый; жизнестойкий
:::tags
английский, слова
```

`:::aliases` перечисляет равнозначные правильные ответы через точку с запятой. Не добавляй приблизительно похожие, но неверные слова.

Автопроверка сравнивает короткий эталон до 80 символов в одной строке без кода и формул. Регистр, лишние пробелы и ё/е не влияют на результат. Пунктуация и остальные символы учитываются. После проверки ты выбираешь трудность. Длинный ответ, формулу или код оценивай по смыслу самостоятельно.

### Пропуски

```markdown
## [cloze] Прямоугольник
Площадь равна {{c1::$S=ab$::формула площади}}.
Периметр равен {{c2::$P=2(a+b)$}}.
:::notes
$a$ и $b$ — длины соседних сторон.
:::tags
математика, геометрия
```

Одинаковый номер скрывает фрагменты вместе. Разные номера создают связанные карточки: этот пример даст две. Номера допустимы от 1 до 99 и начинают счёт заново в каждой заготовке.

Подсказка необязательна: `{{c1::ответ::подсказка}}`. Отдельный `:::answer` для пропуска не нужен; если его добавить, он станет пояснением после раскрытия. Не используй `::` внутри скрываемого ответа для других целей: это разделитель подсказки.

## Дополнительные разделы

Пиши разделитель на отдельной строке без отступа, вне блока кода.

| Разделитель | Что идёт дальше |
| --- | --- |
| `:::answer` | Ответ; обязателен для basic и input |
| `:::notes` | Пояснение, пример, критерии самопроверки |
| `:::aliases` | Допустимые короткие ответы через `;` |
| `:::tags` | Теги через запятую |

Дополнительные разделы можно опускать; их порядок свободный. После разделителя весь текст относится к этому разделу до следующего разделителя или карточки. Закрывающий `:::` не нужен.

## Как оформить код

Небольшой фрагмент внутри предложения заключай в одиночные обратные кавычки: `array.map()`.

Несколько строк заключай в три обратные кавычки. После открывающих кавычек укажи язык, например `javascript`, `typescript`, `python` или `sql`:

````markdown
## [basic] Квадраты чисел в JavaScript
Как получить квадраты чисел, сохранив исходный массив?
```javascript
const numbers = [1, 2, 3];
```
:::answer
```javascript
const squares = numbers.map(number => number * number);
```
:::notes
Результат — [1, 4, 9]. Метод map создаёт новый массив.
````

В карточке сохраняются переносы строк, отступы и символы. Для указанного языка добавляется цветная подсветка, в том числе без сети: JavaScript/js, TypeScript/ts, Python, SQL, C/C++, Java, Rust, HTML, CSS, JSON, YAML и другие распространённые языки. Если язык неизвестен или не указан, код остаётся обычным моноширинным текстом. Для блоков больше 50 000 символов подсветка отключается, чтобы не задерживать телефон.

Длинную строку можно прокрутить внутри блока. Цвета подходят для светлой и тёмной темы. Фрагмент показывается как текст и не выполняется.

Строки `## [basic]` и `:::answer` внутри блока кода не создают карточки и разделы. Если показываешь сами тройные кавычки, оберни весь фрагмент четырьмя кавычками.

## Формулы, таблицы и длинные ответы

Формула внутри предложения: `$x^2$`. Отдельный блок:

```markdown
$$
E = mc^2
$$
```

Математические команды записывай с обратным слешем: `\frac{a}{b}`, `\sqrt{x}`. В файле Markdown слеш один. Формулы отображаются локально и работают без сети.

Поддерживаются **жирный текст**, *курсив*, списки, таблицы Markdown и цитаты. HTML-разметку не используй.

Для развёрнутого ответа удобно выбрать basic, дать краткую суть и список ключевых пунктов. В `:::notes` добавь критерии: что обязательно вспомнить, а что можно изложить своими словами. Если вопрос проверяет несколько независимых мыслей, раздели его на несколько карточек.

## Как добавить изображения

Простой `.md` не содержит сами картинки. Для переноса картинки вместе с карточками собери ZIP с такой структурой:

```text
cards.md
attachments/
  rectangle.png
```

Файл `cards.md` должен лежать **в корне ZIP**, а не внутри дополнительной папки. В нём:

```markdown
## [basic] Диагональ прямоугольника
Чему равна диагональ, если стороны равны 3 и 4?
![Прямоугольник](attachments/rectangle.png)
:::answer
$5$, поскольку $\sqrt{3^2+4^2}=5$.
```

Имя и путь должны точно совпадать с файлом. Используй прямые слеши `/`, удобнее имена без пробелов. Допустимы PNG, JPEG, WebP и GIF до 8 МБ на изображение.

Внешние изображения по адресу сайта автоматически не скачиваются. Можно сначала импортировать текст, затем прикрепить картинку к вопросу или ответу в редакторе Recall.

Для ZIP: до 64 МБ в сжатом и 128 МБ в распакованном виде, до 32 МБ на отдельный файл. Абсолютные пути и `..` не допускаются. Переименование обычного файла в `.zip` архив не создаёт.

## Как подготовить материал с помощью ИИ

1. Открой `ai-prompt.md` из набора и скопируй часть «Готовый запрос».
2. Заполни название, язык и пожелания, вставь свой конспект.
3. Попроси ИИ вернуть только Markdown для Recall, без внешнего блока кода.
4. Проверь факты, формулы, код и варианты ответа. ИИ может ошибаться.
5. Сохрани ответ в `.md` либо вставь в окно импорта. Проверь предпросмотр перед добавлением.

Recall сам не отправляет конспекты в ИИ. Сервис и материал для передачи ты выбираешь самостоятельно.

## Как делать полезные карточки

- Вопрос должен быть понятен без исходного конспекта и не подсказывать ответ.
- Сохраняй условия: нужное значение слова, единицы измерения, область применения формулы, язык и версию технологии.
- Проверяй одну мысль за попытку. Для объяснения связей допустим длинный ответ с ясными критериями.
- Добавляй примеры только там, где они помогают вспомнить правило.
- Перед массовым импортом попробуй небольшой файл и открой несколько карточек.
- Импорт добавляет карточки. Он не редактирует уже существующие по названию. Совпадающее содержание в той же активной колоде пропускается; изменённый ответ может создать новую карточку.

## Частые ошибки

| Что получилось | Что проверить |
| --- | --- |
| Карточки не найдены | Заголовок начинается с `## [basic] Название`, без отступов |
| Нет ответа | Есть отдельная строка `:::answer` и непустой ответ |
| Весь файл выглядит как код | Удали внешний блок кавычек вокруг результата ИИ |
| Часть карточек стала одним блоком | Закрыты все блоки кода, новые заголовки находятся вне них |
| Пропуск не создаётся | Используется `{{c1::ответ}}`, номер от 1 до 99 |
| Появилась лишняя карточка | Подзаголовок внутри ответа должен начинаться с `###` |
| Картинка не появилась | ZIP содержит cards.md в корне; файл и путь attachments/ совпадают |
| Короткий ответ не совпал | Эталон и aliases содержат нужную форму; пунктуация учитывается |
| Получилось больше карточек | Разные номера пропусков создают отдельные карточки |

## Проверка перед импортом

- [ ] Файл сохранён в UTF-8 с расширением .md.
- [ ] У каждой карточки указаны тип и самостоятельный вопрос.
- [ ] У basic и input есть непустой :::answer.
- [ ] Все блоки кода закрыты, формулы и символы сохранены.
- [ ] Нет внешнего блока кода вокруг всего файла.
- [ ] Пропуски и варианты ответа соответствуют исходному материалу.
- [ ] Для ZIP картинки лежат по указанным путям, cards.md — в корне.
- [ ] В предпросмотре нет ошибок, выбрана нужная колода.

Можно скачать эту методичку отдельно, чтобы передать её человеку или ИИ, который готовит твои учебные файлы.
