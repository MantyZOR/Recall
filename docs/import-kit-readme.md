# Набор для импорта в Recall

Распакуй ZIP. Сам этот ZIP не предназначен для импорта.

- import-guide.md — методичка. Её можно передать человеку или ИИ, который делает файлы.
- template.md — заготовка. Замени текст своими вопросами и ответами и импортируй этот .md.
- ai-prompt.md — готовый запрос для ИИ. Это инструкция, а не карточки для импорта.
- examples/code-and-math.md — готовый пример с английским, формулами, кодом и двумя пропусками. Его можно импортировать отдельно; получится 6 карточек.
- examples/choice.md — 2 карточки с выбором ответа: один правильный и несколько правильных, формулы и пояснения к вариантам.

Открой в Recall «Импорт .md» → выбери подготовленный .md или вставь текст → проверь предпросмотр → добавь в новую или существующую колоду.

Для картинок собери отдельный ZIP: cards.md в корне, изображения в attachments/, точные относительные ссылки в cards.md. Подробности есть в import-guide.md.

Все материалы работают без сети. Recall сам не обращается к ИИ.
