# Установить или обновить Recall на Windows

С [последнего релиза](https://github.com/MantyZOR/Recall/releases/latest) скачай только **RecallSetup.exe**. Он подходит для Windows 10/11 x64 и содержит всё приложение. Для запуска не нужно устанавливать Node.js или скачивать исходники.

## Первая установка

Открой установщик и нажми **Установить**. Программа будет в папке **%LOCALAPPDATA%\Programs\Recall**, ярлык Recall появится в меню «Пуск». Права администратора для установки не нужны.

Если Recall уже был распакован из ZIP, сначала останови старую службу в её меню и отключи старый автозапуск, если включал. В установщике нажми **Перенести данные из старой папки…** и выбери папку, где лежит старый Recall.exe. Установщик скопирует данные и сертификаты, а старую папку оставит на месте. Открой новый Recall в том же браузере по прежнему адресу ПК. Если раньше подключал телефон, продолжай открывать прежнюю иконку.

Для работы телефона разреши новую установленную копию в частной сети из меню Recall. Windows запросит подтверждение для настройки брандмауэра, потому что программа теперь запускается из другой папки.

## Обновление

В меню Recall нажми **Проверить обновления** или снова запусти скачанный **RecallSetup.exe** новой версии. Установщик остановит службу этой копии, заменит файлы программы и сохранит базу, изображения, копии, ключи и сертификаты. Открой Recall после установки; в браузере или на телефоне нажми **Обновить**, если появится предложение.

Внутри папки установки **app** — программа, **data** и **certs** — личное состояние. Если при замене обнаружатся вручную добавленные или изменённые файлы программы, старая папка программы будет сохранена рядом. При удалении через «Установленные приложения» личное состояние тоже сохраняется.
